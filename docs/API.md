# API

See `docs/openapi.yaml` and `docs/WEBSERVER.md`.

## Endpoints
- `GET /v1/health`
- `POST /v1/devices/enroll`
- `POST /v1/auth/refresh`
- `POST /v1/auth/login`
- `POST /v1/auth/logout`
- `GET /v1/devices`
- `DELETE /v1/devices/{id}`
- Sync endpoints (`/v1/sync/push`, `/v1/sync/pull`)
- Workout, split, exercise, and body weight endpoints.
